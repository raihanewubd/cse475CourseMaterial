In one paragraph. Boosting builds a strong model by adding weak models one at a time, each one trained to fix what the current ensemble gets wrong. AdaBoost (1997) does this by re-weighting the training samples and voting; XGBoost (2016) does it by fitting each new tree to the gradient of a loss, with explicit regularisation. Both are the same additive recipe, \(F_T(x)=\sum_t \alpha_t h_t(x)\), with a different loss and a different way of taking the step. Tab 3 works AdaBoost by hand on ten points in one dimension, tab 4 on ten points in two dimensions (where the stump must also choose a feature), and tab 5 works two rounds of an XGBoost regression tree with every gain and leaf weight computed. The boosting principle

Slides 7, 22

A weak learner is a model that is only slightly better than guessing. Boosting trains weak learners in sequence: each new one is trained with extra attention to the samples the current ensemble gets wrong, and the final model is a weighted sum of all of them,

\[ F_T(x)=\sum_{t=1}^{T}\alpha_t\,h_t(x), \qquad H(x)=\operatorname{sign}\big(F_T(x)\big)\ \text{(classification)}. \]

This is forward stagewise additive modelling: at stage \(t\) the earlier terms are frozen and only \((\alpha_t,h_t)\) is chosen, to reduce some loss \(L\) on the training set:

\[ (\alpha_t,h_t)=\arg\min_{\alpha,h}\ \sum_{i=1}^{N} L\big(y_i,\ F_{t-1}(x_i)+\alpha\,h(x_i)\big). \]

The two algorithms in this lecture are two instances of this one recipe, and the comparison in tab 6 is easiest to read through it:

Why this view matters. The slide deck says AdaBoost is "sensitive to outliers" and XGBoost "has regularisation", as if the second explained the first. It does not. AdaBoost's outlier sensitivity comes from the exponential loss: a sample on the wrong side by margin \(m=yF(x)=-3\) costs \(e^{3}=20.1\) under exponential loss but only \(\ln(1+e^{3})=3.05\) under log-loss, so the exponential loss lets one bad point dominate the next round. Gradient boosting with log-loss is less sensitive because of the loss, before any \(\lambda\) is applied.

Seminal paper 1 — AdaBoost (1997)

Slide 4

Freund, Y. & Schapire, R. E. (1997). A Decision-Theoretic Generalization of On-Line Learning and an Application to Boosting. Journal of Computer and System Sciences 55(1), 119–139. DOI 10.1006/jcss.1997.1504. Gödel Prize 2003.

  • Formalised the weak-learner idea and proved that weak learners can be combined into an arbitrarily strong one.
  • First practical boosting algorithm; no need to know the weak learners' accuracies in advance (that is the "adaptive" in AdaBoost).
  • Training error bound \( \text{err}_{\text{train}} \le \prod_{t} 2\sqrt{\varepsilon_t(1-\varepsilon_t)} \), which falls exponentially in \(T\) when every \(\varepsilon_t \le \tfrac12-\gamma\). The factor \(2\sqrt{\varepsilon_t(1-\varepsilon_t)}\) is exactly the normaliser \(Z_t\) computed in every round of the examples; we check this in tab 3.
  • Connections to game theory and on-line learning.

Seminal paper 2 — XGBoost (2016)

Slide 5

Chen, T. & Guestrin, C. (2016). XGBoost: A Scalable Tree Boosting System. Proc. 22nd ACM SIGKDD, 785–794. DOI 10.1145/2939672.2939785. Builds on Friedman's gradient boosting machine (2001).

  • Regularised objective (\(\gamma\) per leaf and \(\lambda\) on leaf weights) with a second-order Taylor step.
  • Sparsity-aware split finding: a learned default direction for missing values.
  • Weighted quantile sketch for approximate split finding on large data.
  • Cache-aware, parallel (across features, within a tree) and distributed implementation.
  • Became the default winning tool on tabular Kaggle competitions around 2015–2017.

2. AdaBoost — concept, algorithm, maths

Core concept

Slide 7

Weak learner

A model slightly better than random guessing. In this lecture: a decision stump (a depth-1 tree).

Sample weights \(w_i\)

Every training sample carries a weight. Samples the current stump gets wrong have their weight increased for the next round.

Classifier weight \(\alpha_t\)

Each stump gets a vote weight from its weighted error: lower error, larger \(\alpha_t\).

Final prediction

Weighted majority vote \(H(x)=\operatorname{sign}\!\big(\sum_t \alpha_t h_t(x)\big)\).

What is a decision stump?

Slide 8

A stump tests one feature \(x_j\) against one threshold \(\tau\) and returns a class on each side. With two classes it has two orientations ("polarities"):

\[ h(x)=\begin{cases}+1 & x_j\le\tau\\ -1 & x_j>\tau\end{cases} \qquad\text{or its flip}\qquad h(x)=\begin{cases}-1 & x_j\le\tau\\ +1 & x_j>\tau.\end{cases} \]

The stump search therefore ranges over feature × threshold × polarity. With \(D\) features and \(N\) distinct values per feature there are at most \(2D(N-1)\) candidate stumps; the thresholds are taken halfway between consecutive sorted values (scikit-learn does the same). A flipped stump has weighted error \(1-\varepsilon\) of the unflipped one, so searching both polarities guarantees \(\varepsilon_t\le\tfrac12\).

Algorithm, step by step

Slides 9–10

Binary labels \(y_i\in\{-1,+1\}\), training set \(\{(x_i,y_i)\}_{i=1}^{N}\), \(T\) rounds.

  1. Initialise \(w_i=1/N\) for all \(i\).
  2. For \(t=1,\dots,T\):
    1. Train the stump \(h_t\) that minimises the weighted error \(\displaystyle \varepsilon_t=\sum_{i} w_i\,\mathbb{1}[y_i\ne h_t(x_i)]\).
    2. Compute the classifier weight \(\displaystyle \alpha_t=\tfrac12\ln\frac{1-\varepsilon_t}{\varepsilon_t}\).
    3. Update \(w_i\leftarrow w_i\,e^{-\alpha_t y_i h_t(x_i)}\): correct samples are multiplied by \(e^{-\alpha_t}<1\), wrong ones by \(e^{+\alpha_t}>1\).
    4. Normalise \(w_i\leftarrow w_i/Z_t\) with \(Z_t=\sum_j w_j\), so the weights sum to 1 again.
  3. Output \(H(x)=\operatorname{sign}\!\big(\sum_{t=1}^{T}\alpha_t h_t(x)\big)\).

Where \(\alpha_t\) comes from (the exponential-loss view)

New

Take the stagewise objective from tab 1 with the exponential loss and write \(w_i\propto e^{-y_iF_{t-1}(x_i)}\) for the weights left over from earlier rounds. Then

\[ \sum_i e^{-y_i\left(F_{t-1}(x_i)+\alpha h(x_i)\right)} \;\propto\; \sum_i w_i\,e^{-\alpha y_i h(x_i)} \;=\; e^{-\alpha}\,(1-\varepsilon)\;+\;e^{+\alpha}\,\varepsilon . \]

For fixed \(\alpha>0\) this is smallest when \(\varepsilon\) is smallest — so \(h_t\) must minimise the weighted error, step (a). Setting the derivative in \(\alpha\) to zero, \(-e^{-\alpha}(1-\varepsilon)+e^{\alpha}\varepsilon=0\), gives \(e^{2\alpha}=\frac{1-\varepsilon}{\varepsilon}\), i.e. step (b). Substituting back, the minimum value is \(2\sqrt{\varepsilon(1-\varepsilon)}=Z_t\), which is why the normaliser equals the error-bound factor.

Two consequences you will see in the examples. (1) After the update, the stump just trained has weighted error exactly \(\tfrac12\) on the new weights — its misclassified samples now carry total weight \(\varepsilon_t e^{\alpha_t}/Z_t=\tfrac12\). It cannot be chosen again in the very next round. (2) The same stump can be chosen again two rounds later, once the weights have moved on; Example A does this (rounds 1 and 3 pick the same cut).

Advantages and disadvantages

Slide 20

Advantages

  • Few hyperparameters (\(T\), optionally a shrinkage factor).
  • Any weak learner can be the base classifier.
  • Training error bound falls exponentially with \(T\) (proven, under the weak-learning condition).
  • Strong accuracy from very shallow stumps; no feature engineering needed to pick which feature each stump uses.
  • Interpretable: each stump and its \(\alpha_t\) can be read off.

Disadvantages

  • Sensitive to label noise and outliers — a consequence of the exponential loss (tab 1 note).
  • Can overfit noisy data as \(T\) grows.
  • Rounds are sequential, so wall-clock time grows linearly with \(T\). (Gradient boosting is sequential across trees too; XGBoost parallelises within a tree, see tab 6.)
  • Degrades if the base learners are too strong (they stop being "weak" and the vote loses diversity).
  • No explicit penalty on model complexity.

Two lessons. First, the bound \(\prod_t Z_t\) on training error always decreases (0.80 → 0.62 → 0.58 → 0.55 → 0.51 → 0.45 over six rounds), but the actual training error is not monotone: it went 0.2, 0.3, 0.2, 0.2, 0.1, 0.2. Second, sample 5 is a \(+1\) with \(-1\) neighbours on both sides; to make \(F(5)>0\) the stumps bounding the interval \(4<x\le5\) (an "\(x\le5\)" cut and a flipped "\(x\le4\)" cut) must together outweigh \(h_1\) and \(h_3\) there, and whether the algorithm gets there depends on how the weights of 4, 6, 7 and 8 keep moving — we did not run it to convergence. In practice you would stop at the \(T\) that minimises validation error, not training error.

5. XGBoost — objective, second-order step, worked regression

Overview

Slide 22

XGBoost is an optimised, regularised implementation of gradient tree boosting. Instead of re-weighting samples, each new tree \(f_t\) is fitted to the gradient of the loss at the current prediction (for squared loss: the residuals). The model after \(T\) rounds is

\[ F_T(x)=F_0(x)+\eta f_1(x)+\eta f_2(x)+\cdots+\eta f_T(x), \]

where \(\eta\in(0,1]\) is the learning rate (shrinkage) and each \(f_t\) is a regression tree that maps \(x\) to the weight \(w_j\) of the leaf \(x\) lands in. Compare AdaBoost: there the "trees" are stumps returning \(\pm1\), the step size \(\alpha_t\) is solved per round, and the loss is exponential.

Regularised objective

Slide 23
\[ \text{Obj}=\sum_{i=1}^{N} L(y_i,\hat y_i)\;+\;\sum_{k=1}^{T}\Omega(f_k),\qquad \Omega(f)=\gamma\,T_{\text{leaves}}+\tfrac12\lambda\sum_{j=1}^{T_{\text{leaves}}} w_j^{2}. \]
\(L(y_i,\hat y_i)\)any differentiable loss: squared error for regression, log-loss for classification. \(T_{\text{leaves}}\)number of leaves in the tree; \(\gamma\) charges a fixed price per leaf, so a split must earn more than \(\gamma\) to be kept. \(w_j\)the value predicted by leaf \(j\); \(\lambda\) is an L2 penalty that shrinks leaf values towards zero.

The library also offers an L1 term \(\alpha\sum_j|w_j|\) (reg_alpha); it is omitted from the derivation below.

Second-order Taylor step, leaf weights and split gain

Slide 24

At round \(t\) the prediction is \(\hat y_i^{(t)}=\hat y_i^{(t-1)}+f_t(x_i)\). Expanding \(L\) to second order around \(\hat y_i^{(t-1)}\) and dropping terms that do not depend on \(f_t\):

\[ \text{Obj}^{(t)}\approx\sum_{i=1}^{N}\Big[g_i\,f_t(x_i)+\tfrac12 h_i\,f_t(x_i)^2\Big]+\Omega(f_t),\qquad g_i=\frac{\partial L}{\partial\hat y_i},\quad h_i=\frac{\partial^2L}{\partial\hat y_i^2}, \]

both derivatives evaluated at the previous prediction \(\hat y_i^{(t-1)}\). Because every sample in leaf \(j\) receives the same value \(w_j\), group the sum by leaf with \(G_j=\sum_{i\in I_j}g_i\) and \(H_j=\sum_{i\in I_j}h_i\):

\[ \text{Obj}^{(t)}\approx\sum_{j=1}^{T_{\text{leaves}}}\Big[G_j w_j+\tfrac12(H_j+\lambda)w_j^2\Big]+\gamma T_{\text{leaves}} . \]

Each bracket is a parabola in \(w_j\). Setting its derivative to zero gives the optimal leaf weight and, substituting back, the objective value of a tree structure:

\[ w_j^{*}=-\frac{G_j}{H_j+\lambda},\qquad \text{Obj}^{*}=-\tfrac12\sum_{j}\frac{G_j^{2}}{H_j+\lambda}+\gamma T_{\text{leaves}} . \]

Splitting a leaf with totals \((G,H)\) into left \((G_L,H_L)\) and right \((G_R,H_R)\) changes the objective by the split gain; the split is kept only if it is positive:

\[ \text{Gain}=\tfrac12\left[\frac{G_L^{2}}{H_L+\lambda}+\frac{G_R^{2}}{H_R+\lambda}-\frac{(G_L+G_R)^{2}}{H_L+H_R+\lambda}\right]-\gamma . \]

The factor \(\tfrac12\) in the squared loss is what makes \(h_i=1\); with \((y-\hat y)^2\) you would get \(g_i=2(\hat y_i-y_i)\) and \(h_i=2\), and the leaf weights would change accordingly.

Key engineering features

Slide 28

Regularisation

\(\gamma\) per leaf, \(\lambda\) (L2) and \(\alpha\) (L1) on leaf weights, plus row and column subsampling.

Missing values

Sparsity-aware split finding learns a default direction for missing values at every node; no imputation needed.

Pruning

A split with Gain ≤ 0 (after subtracting \(\gamma\)) is removed, bottom-up.

Parallel split finding

Candidate splits for different features are evaluated in parallel within one tree. The trees themselves are still built one after another.

Column subsampling

A random subset of features per tree (and optionally per level), as in random forests — decorrelates the trees.

Early stopping

Training stops when a validation metric has not improved for a set number of rounds.

Why the loss matters more than \(\lambda\) for outliers

New

Write the margin of a sample as \(m=yF(x)\): positive when correct, negative when wrong, larger in magnitude when the ensemble is more confident. The per-sample loss as a function of \(m\):

Margin \(m\)Exponential \(e^{-m}\)Log-loss \(\ln(1+e^{-m})\)Hinge \(\max(0,1-m)\)
+3 (confidently right)0.0500.0490
0 (on the boundary)10.6931
−12.7181.3132
−3 (confidently wrong, e.g. a mislabelled point)20.093.054

A mislabelled point that the ensemble is (correctly, by the true pattern) confident about costs the exponential loss 20 — roughly the weight of 400 well-classified points — so the next AdaBoost round is driven by it. Log-loss grows only linearly in \(-m\), so a gradient-boosted log-loss model keeps paying attention to the bulk. That is the mechanism behind "AdaBoost is sensitive to noise"; \(\lambda\) on leaf weights is a second, smaller effect that caps how far any one leaf moves per tree.

AdaBoost from scratch (practice question 6, reference solution)

New
import numpy as np

def best_stump(X, y, w):
    """Search feature x threshold x polarity; return (j, tau, pol, eps)."""
    best = None
    for j in range(X.shape[1]):
        v = np.unique(X[:, j])
        for tau in (v[:-1] + v[1:]) / 2:          # midpoints
            for pol in (+1, -1):
                h = np.where(X[:, j] <= tau, pol, -pol)
                eps = w[h != y].sum()
                if best is None or eps < best[3]:
                    best = (j, tau, pol, eps)
    return best

def adaboost(X, y, T):
    N = len(y); w = np.full(N, 1.0 / N); model = []
    for t in range(T):
        j, tau, pol, eps = best_stump(X, y, w)
        alpha = 0.5 * np.log((1 - eps) / eps)
        h = np.where(X[:, j] <= tau, pol, -pol)
        w = w * np.exp(-alpha * y * h); w /= w.sum()
        model.append((alpha, j, tau, pol))
    return model

def predict(model, X):
    F = sum(a * np.where(X[:, j] <= tau, pol, -pol) for a, j, tau, pol in model)
    return np.sign(F)

8. Summary, practice questions, references

Key takeaways

Slide 36
Boosting principleSequential, additive: \(F_T=\sum_t\alpha_t h_t\); each new learner targets what the current ensemble gets wrong. AdaBoost (1997)Re-weights samples; \(\alpha_t=\tfrac12\ln\frac{1-\varepsilon_t}{\varepsilon_t}\); the stump just trained has weighted error \(\tfrac12\) on the new weights; the normaliser \(Z_t=2\sqrt{\varepsilon_t(1-\varepsilon_t)}\) is the training-error-bound factor. All of this is forward stagewise fitting of the exponential loss. XGBoost (2016)Fits trees to gradients \(g_i\) and hessians \(h_i\); \(w_j^*=-G_j/(H_j+\lambda)\); split gain \(\tfrac12[\,G_L^2/(H_L+\lambda)+G_R^2/(H_R+\lambda)-G^2/(H+\lambda)\,]-\gamma\); learning rate \(\eta\) shrinks each tree. From the examplesWeighted error is not an error count (tab 4, round 3). Training accuracy is not monotone in \(T\) even though its bound is (tab 3, rounds 4–6). Split ties happen on symmetric data (tab 5, round 1). Choose AdaBoost whendata are clean, interpretability matters, or you want a quick baseline on small data. Choose XGBoost whendata are large or messy, have missing values, or you need the best tabular accuracy.
