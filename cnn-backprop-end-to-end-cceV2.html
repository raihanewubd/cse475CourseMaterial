The Big Idea & the Running Example

Backpropagation is one chain rule applied layer by layer. This tutorial traces it through a complete — if tiny — CNN classifier: a two-channel image patch goes through one convolution, a ReLU, a flatten, one fully connected layer, and a softmax; categorical cross-entropy scores the prediction against a one-hot label; then the error flows backward and every one of the network’s 24 parameters is updated by SGD. One example is defined below and reused in every step.

Categorical Cross-Entropy Loss

Brief: the loss is the negative log-probability the model gave to the correct class (implements F6).
Input: p = [0.2447, 0.6652, 0.0900]  from Step 4;  y = [1, 0, 0]  Section 0
Output: L = 1.4077.

EQUATION

L = −Σk=1..3 yk ln pk = −ln ptrue
ykone-hot label — kills every term but the true class
−ln ptruelarge when the model doubts the truth, → 0 as ptrue → 1

WITH OUR NUMBERS

L = −( 1·ln 0.2447 + 0·ln 0.6652 + 0·ln 0.0900 )
   = −ln 0.2447
L = 1.4077
How wrong is “wrong”? Had the true class been 2 (the model’s guess), the loss would be −ln 0.6652 = 0.4077. The difference, 1.4077 − 0.4077 = 1.0000, is exactly the logit gap z2 − z1: cross-entropy differences between candidate labels are log-odds.

Upstream Gradient at the Logits: δz = p − y

Brief: the whole softmax–cross-entropy block has a one-line gradient, δz = p − y — derived below, then verified through the full Jacobian (implements B1). δ is the Greek letter delta — the traditional symbol for an error signal. map: L ⇒ z
Input: p = [0.2447, 0.6652, 0.0900]  from Step 4;  y = [1, 0, 0]  Section 0
Output: δz = [−0.7553, +0.6652, +0.0900]⊤.

Why p − y. The two chain-rule factors are ∂L/∂pk = −yk/pk and the softmax Jacobian ∂pk/∂zj = pk(1[k=j] − pj). Multiply and sum:

∂L/∂zj = Σk (−yk/pk) · pk(1[k=j] − pj) = −Σk yk·1[k=j] + pj Σk yk = −yj + pj = pj − yj

The pk factors cancel — the softmax analogue of the sigmoid–BCE cancellation, in K dimensions. This is why frameworks fuse softmax with cross-entropy into a single op.

Softmax–CCE gradients only redistribute probability mass. Negative on the true class, positive on the rest, summing to zero: gradient descent will raise the true class’s logit and lower the competitors’.

EQUATION

SANITY CHECK — AND AN HONEST WRINKLE

The prediction flipped: the largest logit now belongs to class 1, the true class. One SGD step fixed the misclassification — the gradients did exactly what Step 6 said they would.

But look at Z′: unit (0,0), alive before, is now dead (−0.1474), and (0,1) is deader (−2.5720). An aggressive step on a single example can kill units even while it fixes the prediction — one reason real training averages gradients over mini-batches and uses smaller learning rates.

The full loop, tallied. One example, one label, 24 parameters: 6 forward equations, 7 backward ones, every gradient expanded term by term, and a measurable improvement at the end. Four things worth remembering:

1. δz = p − y sums to zero — softmax–CCE only redistributes probability mass among classes.
2. The dead unit at (0,1) blocked learning both ways: a zero column in ∂L/∂Wfc, and zero transmitted δ.
3. FC gradient = outer product; conv gradient = cross-correlation. Same chain rule, different structure.
4. The tie ∂L/∂W[0,0,1] = ∂L/∂W[1,1,1] is the input’s own symmetry, not backprop’s.

What this toy simplifies. One training example (no mini-batch averaging), integer initial weights rather than random ones, η = 0.1 chosen so updates are visible (hence the dramatic swing and the newly dead unit), no stride/padding/pooling, and the chain stops at this conv layer — a deeper network would also need ∂L/∂X to keep propagating. The mechanics, however, are exactly what full-size CNNs run.
