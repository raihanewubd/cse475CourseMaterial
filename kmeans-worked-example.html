Seven individuals, each described by two variables. There are no labels: the task is to split them into K = 2 groups so that points in a group are close to each other.

What K-means is trying to minimise

K-means looks for centroids m1, m2 and an assignment of every point to one of them that makes the sum of squared distances as small as possible:

J = Σj=1..K Σx ∈ Sj ‖x − mj‖²

It does not solve this exactly. It alternates two easy steps, each of which can only lower J (or leave it unchanged):

Choose K = 2 and pick two initial centroids
↓
Assignment step. For every point compute its Euclidean distance to each centroid and put it in the cluster of the nearest centroid.d(p, m) = √[(px − mx)² + (py − my)²]
↓
Update step. Move each centroid to the mean of the points now assigned to it.mj = ( mean of x-values , mean of y-values ) over the points in cluster j
↓
Stop test. If no point changed cluster (equivalently, the centroids did not move), stop. Otherwise go back to the assignment step.
↓
Output the final clusters and centroids
Reading the diagrams Circles are data points, numbered 1–7. Stars are centroids: m1 and m2. A dashed line joins each point to the centroid it is assigned to. A green arrow shows a centroid moving from its old position (faded star) to its new one. A point with an orange ring is one whose cluster changed in that pass.

Things to take from this example

  • J never goes up. 33.25 → 11.23 → 8.53. The assignment step can only pick a nearer centroid for each point, and the mean is the point that minimises the sum of squared distances to a set, so the update step can only lower J too. That is why K-means always terminates.
  • Convergence is to a local minimum, not necessarily the best one. This dataset happens to be so well separated that every choice of two data points as starting centroids (all 42 ordered pairs) ends at the same partition, only the number of passes differs. That is a property of this data, not of K-means: with overlapping or elongated clusters, different starts do end in different splits with different J. Running K-means several times from different starts and keeping the lowest J is standard practice; K-means++ chooses the starts more carefully.
  • Ties must be broken by a rule. Point 3 was equidistant at the start. Different tie-break rules can produce different first iterations, although here they converge to the same answer.
  • The final centroids are not data points. (1.25, 1.50) and (3.90, 5.10) are averages. If you need a real object as the cluster representative, that is K-medoids (next in the lecture).
  • Scale matters. Euclidean distance treats a unit of Variable 1 the same as a unit of Variable 2. If the variables had different units, they should be standardised first, or the larger-range variable would dominate every distance.
Try it yourself Re-run the example with initial centroids m1 = point 2 = (1.5, 2.0) and m2 = point 6 = (4.5, 5.0); it should settle in two passes. Then start from m1 = point 5 and m2 = point 6, which sit only one unit apart, and count how many passes it takes to reach the same answer (it is five). Finally, add an eighth point at (3.0, 2.5) and see whether the two starts still agree.
